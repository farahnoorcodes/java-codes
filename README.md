# java-codes

This repository contains my journey of learning Java from scratch — covering core concepts, syntax, and hands-on practice programs as I work through the language step by step.

## About

This repo is a day-by-day log of Java topics as I learn and implement them. Each folder or file corresponds to a concept, with small practice programs demonstrating the idea.

## Topics Covered 

- Hello World / Basic Syntax
- Variables and Data Types
- Operators
- Conditional Statements (if-else, switch)
- Loops (for, while, do-while)
- Arrays
- Strings
- Methods / Functions
- OOP Basics (Classes & Objects)
- Constructors
- Inheritance
- Polymorphism
- Encapsulation & Abstraction
- Interfaces
- Exception Handling
- Collections (ArrayList, HashMap, etc.)
- File Handling
- Multithreading (Basics)

## How to Run

Each `.java` file can be compiled and run using:

```bash
javac filename.java
java ClassName
```

Make sure the class name matches the file name for public classes.

## Notes

- `.class` files are excluded from this repo via `.gitignore`, since they are compiler-generated and not part of the source code.
- This repo is purely for learning and practice purposes.
